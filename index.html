About this atlas

Built from PHMSA's public "flagged incident" files — the same records US regulators use to track 20-year pipeline-safety trends.

Real regulator data

Every incident is an official PHMSA filing, 1986–2026, cleaned from 668-column source files.

Four systems

Hazardous liquid, gas transmission, gas distribution and LNG — mapped separately and combined.

Honest scope

US only, since PHMSA regulates US pipelines. Pre-2002 incidents lack coordinates, so they feed charts, not dots.

Self-contained

Plain HTML & Leaflet. No build tools, works offline, opens in any browser.
